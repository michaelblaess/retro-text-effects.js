retro-text-effects.js

A browser port of TerminalTextEffects (TTE), the Python terminal-effects library - rebuilt in vanilla JavaScript. Thirteen text and canvas effects, no dependencies, no external requests, one self-contained file you can drop into any page.

Effects

Thirteen effects, two flavours

Text effects rewrite the element's text content - no canvas, the text stays selectable. Canvas effects lay a temporary canvas over the element for free 2D character motion, then fade out to reveal the untouched text.

Text effects (no canvas)

🔓

decrypt

Every cell flickers through random glyphs and then locks onto its final character. Whitespace stays put, so a framed layout never jumps.

⌨️

print

Typewriter reveal, character by character, with a blinking head cursor running ahead of the text.

🟩

matrix

Columns rain down from the top, each settling row by row until the message stands still.

🔀

overflow

Lines scramble and cycle a few times before snapping back into their final order.

📺

crt

A persistent retro-monitor treatment: phosphor glow, subtle scanlines and a faint flicker. Toggle it on, cancel() to remove it.

Canvas effects

🌧️

matrix2

The classic falling-glyph screen: katakana rain over the element, fading out to reveal the text.

💧

rain

Every character falls from above straight down into its place, staggered like a steady drizzle.

🏀

bouncyballs

Characters drop in as coloured balls, bounce a few times on their landing row and settle into the glyph.

✨

scattered

All characters start scattered across the stage and glide, eased and staggered, to their final spot.

💥

expand

The whole text bursts outward from the centre, every character easing into position.

🎆

fireworks

Rockets launch from the bottom, explode into sparks and throw their characters to the text, volley by volley.

🕳️

blackhole

Characters spiral into a singularity, vanish - then a shockwave throws them back out into the text.

🔴

laseretch

A laser beam from the corner traces the text in, character by character, throwing off falling sparks.

Getting started

Usage

Download retro-text-effects.min.js from the releases and include it with a plain script tag. No build step, no dependencies.

<script src="retro-text-effects.min.js"></script>
<script>
  RetroTextEffects.decrypt('#log');
  RetroTextEffects.print('#banner', { cps: 80 });
  RetroTextEffects.fireworks('#log', { speed: 1.2 });
  const screen = RetroTextEffects.crt('#log');  // screen.cancel() removes it
</script>
